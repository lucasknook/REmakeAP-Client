# Disclaimer on LLM usage
This runtime client, including the reverse engineering needed to make it work, is made using ChatGPT's GPT-5.6-Sol model.
All files in this folder, with the sole exception of this README, are written almost exclusively with this model.
This implementation serves purely as a starting point in understanding REmake's architecture, to develop a stable and correct client, and does not represent what the released mod will look like.
